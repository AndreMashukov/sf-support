# CONTEXT.md Format

## Structure

```md
# {Context Name}

{One or two sentence description.}

## Language

**Term**:
{One or two sentences.}
_Avoid_: synonym, other word
```

## Rules

- Be opinionated. Pick one word. List others under `_Avoid_`.
- Keep definitions tight.
- Only project-specific terms. No general programming jargon.
